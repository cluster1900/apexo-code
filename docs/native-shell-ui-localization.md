# Native Process manager localization

The existing Tasks manager presents native subagent Tasks and native Shell Processes with explicit source identity. This draft adds 19 English, Simplified Chinese and Traditional Chinese phrases. Existing English values remain unchanged. Other locale dictionaries continue to use the shared English fallback for these new keys; this slice does not claim all-language coverage.

The semantic source is the English dictionary. The reviewed wording distinguishes reading output, a bounded wait, stopping a process, and stopping an active model turn. Closing the panel does not stop a process. Restart-interrupted work does not resume automatically. The list describes its newest-100 scope and does not claim a global running total.

Terminology was cross-checked against the maintained [VS Code Simplified Chinese corpus](https://raw.githubusercontent.com/microsoft/vscode-loc/main/i18n/vscode-language-pack-zh-hans/translations/main.i18n.json), [VS Code Traditional Chinese corpus](https://raw.githubusercontent.com/microsoft/vscode-loc/main/i18n/vscode-language-pack-zh-hant/translations/main.i18n.json), [Firefox Simplified Chinese process manager](https://raw.githubusercontent.com/mozilla-l10n/firefox-l10n/main/zh-CN/toolkit/toolkit/about/aboutProcesses.ftl), and [Firefox Traditional Chinese process manager](https://raw.githubusercontent.com/mozilla-l10n/firefox-l10n/main/zh-TW/toolkit/toolkit/about/aboutProcesses.ftl). Traditional Chinese interruption wording was also checked against the [Taiwan Ministry of Education entry for 中斷](https://dict.concised.moe.edu.tw/dictView.jsp?ID=31132&la=0&powerMode=0).

Simplified Chinese consistently uses 进程; Traditional Chinese uses 處理程序, matching Firefox's process-management context. VS Code contains mixed 程序/處理序/處理程序 forms, so its individual glossary entries were not applied mechanically. Output is 输出/輸出, and interruption is 中断/中斷. Shell remains an established developer term. Process IDs and command/output text are identifiers or user data and are not translated.

Complete phrases were reviewed in context and placeholders preserved. This is a corpus-grounded author review, not native-speaker signoff. Region-specific Traditional Chinese wording remains a useful focus for further review. Actual browser/native screenshots and counts are listed in the Process UI acceptance notes.
