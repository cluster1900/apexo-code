# Native MCP OAuth localization review

Scope: 17 new App labels in English, Simplified Chinese and Traditional Chinese. Existing source copy is preserved. Other App locales fall back to English; the current shared terminal manager remains English. Integrated production-browser and actual rebuilt native-window checks each passed nine checks across all three locales and both manager entrypoints. All six localized native screenshots were inspected. Native-speaker review remains pending.

Terminology was checked on 2026-10-15 against the maintained [VS Code Simplified Chinese corpus](https://github.com/microsoft/vscode-loc/blob/main/i18n/vscode-language-pack-zh-hans/translations/main.i18n.json) and [Traditional Chinese corpus](https://github.com/microsoft/vscode-loc/blob/main/i18n/vscode-language-pack-zh-hant/translations/main.i18n.json), including authentication prompts and MCP connection wording. The independent Firefox account corpora for [Simplified Chinese](https://github.com/mozilla-l10n/firefox-l10n/blob/main/zh-CN/browser/browser/accounts.ftl) and [Traditional Chinese](https://github.com/mozilla-l10n/firefox-l10n/blob/main/zh-TW/browser/browser/accounts.ftl) provide account-verification and browser-action context. The Taiwan Ministry of Education's [授權 entry](https://dict.revised.moe.edu.tw/dictView.jsp?ID=130463&la=0&powerMode=0) grounds the authorization term.

The host-placement hint deliberately states that the browser must run on the server computer. [Microsoft's Simplified Chinese redirect-URI guidance](https://learn.microsoft.com/zh-cn/azure/active-directory/develop/reply-url) uses 环回; the [Traditional Chinese IPAddress reference](https://learn.microsoft.com/zh-tw/dotnet/api/system.net.ipaddress) uses 迴路位址. The longer explanatory hint and Traditional Chinese 認證資料 deserve native-speaker review; this terminology review does not claim that review occurred.

Saved credentials are distinguished from enabling or connecting a server. Busy completion says to retry after project work finishes. Cancelled, expired, invalid configuration and corrupt storage have complete safe messages; no code, token, private path or issuer response is interpolated. OAuth and Apexo retain their product/protocol spelling. These 17 keys have no interpolation placeholders.
