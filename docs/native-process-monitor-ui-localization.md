# Native Shell and Monitor manager localization review

The existing Tasks manager retains its existing English labels. Ten additive typed keys describe the combined native list and Monitor metadata. App uses complete en/zh/zht phrases through the shared translator; other locales retain its English fallback. Both terminal modes retain the existing English-only terminal convention.

Terminology was checked against the [Firefox zh-CN process manager](https://raw.githubusercontent.com/mozilla-l10n/firefox-l10n/main/zh-CN/toolkit/toolkit/about/aboutProcesses.ftl), its [zh-TW counterpart](https://raw.githubusercontent.com/mozilla-l10n/firefox-l10n/main/zh-TW/toolkit/toolkit/about/aboutProcesses.ftl), and Microsoft's maintained [VS Code Simplified Chinese](https://raw.githubusercontent.com/microsoft/vscode-loc/main/i18n/vscode-language-pack-zh-hans/translations/main.i18n.json) and [Traditional Chinese](https://raw.githubusercontent.com/microsoft/vscode-loc/main/i18n/vscode-language-pack-zh-hant/translations/main.i18n.json) corpora. Firefox supports the existing regional choice of 进程 versus 處理程序. VS Code's Traditional Chinese corpus uses both 處理序 and 處理程序 by context; this slice keeps the existing Apexo/Firefox manager vocabulary. VS Code's timeout configuration uses 逾時 and distinguishes zero as no timeout, supporting the Traditional Chinese no-deadline wording. The [Taiwan Ministry of Education dictionary's own operation instructions](https://dict.concised.moe.edu.tw/page.jsp?ID=9) use 批次 for grouped operations; its [教育百科 中斷 entry](https://pedia.cloud.edu.tw/Entry/Detail/?title=%E4%B8%AD%E6%96%B7) provides the ordinary interruption sense. These are terminology/context checks, not claims of native-speaker approval.

The canonical `monitor` tool identifier remains unchanged; descriptive manager labels use localized monitoring terminology. Shell is retained as an established developer term; API names, IDs and milliseconds remain code/unit tokens. Count labels describe accepted/suppressed batches, explicitly not provider calls or lines. Persistent means a running-process policy, never restart survival. The separate explanation distinguishes model Stop (delivery suppression until actual new input) from Stop process (ending the command). Native speakers should particularly review persistent-policy phrasing, since a literal durable-storage reading would be misleading.

No new plural-category or locale branch was introduced. Dynamic placeholders remain numeric values and counts, and all existing English keys remain unchanged. The private production browser passed eight checks across en/zh/zht, including actual restart and overload receipts. The Simplified Chinese overload and Traditional Chinese restart screenshots were visually inspected: full phrases, dynamic batch values and timeout units are legible. The actual private native window passed the same eight checks; its English running and Traditional Chinese overload screenshots were also inspected. App and Desktop artifacts were built from the private implementation; backend acceptance is not renderer evidence.
