Core Architecture

Engineered for Autonomous Software Engineering

Built from the ground up with a durable local agent runtime rather than a thin wrapper around a single model vendor.

/goal Closed-Loop

Autonomous Goals

Set an objective and verification criteria. Apexo plans, edits, and runs checks across iterations until the goal passes verification.

/workflow Multi-Session

Parallel Workflows

Run multi-stage engineering workflows in isolated child sessions with per-step model and effort routing while your main chat stays free.

/tasks · /loop Orchestration

Tasks & Subagents

Coordinate background commands, recurring cron-like loops, and specialized subagents from a single real-time task manager.

/memory · /dream Long-Term Context

Persistent Memory

Retain codebase conventions and user preferences across sessions. Inspect with /memory, record with /remember, and consolidate with /dream.

/sandbox OS Isolation

Native Command Sandbox

Enforce kernel-level sandboxing via macOS seatbelt and Linux bubblewrap to restrict file writes and network access per session.

/hooks · /btw Control & Flow

Lifecycle Hooks & Side Queries

Manage repository hooks with explicit trust controls (/hooks), or ask quick side questions mid-turn (/btw) without polluting context.

Direct Provider Access

Native OAuth & Universal Model Support

Credentials stay on your machine. Requests go straight to the model provider you configure — no hosted proxy, no telemetry relay.

Google Gemini & Antigravity

Zero Re-Auth

Reuse your local Antigravity CLI (agy) Google session directly without re-authorizing, or connect via API key. Supports thinking summaries and multimodal inputs.

agy login / GOOGLE_GENERATIVE_AI_API_KEY gemini-2.5-pro

xAI Grok & Grok Build

Device OAuth

Sign in with SuperGrok or X Premium via device-code OAuth (apexo auth login), or use XAI_API_KEY. Full support for Grok 4 and Grok Build agent workflows.

apexo auth login / XAI_API_KEY grok-4.7 · grok-build-0.1

Quickstart & Config

Up and Running in Seconds

Use intuitive CLI subcommands and configure custom providers globally or per repository with JSON Schema validation.

Essential CLI Commands apexo --help 
# Start interactive Terminal UI in current project
apexo

# Sign in to Antigravity, xAI Grok (OAuth), or set an API key
apexo auth login

# List all available models across providers
apexo models

# Launch local server and open Web UI
apexo web

# Interactive slash commands inside TUI / Desktop:
# /connect  /models  /themes  /goal  /workflow  /tasks  /memory  /btw
Configuration (~/.config/apexo/apexo.jsonc) schemas/config.json 
{
  "$schema": "https://raw.githubusercontent.com/cluster1900/apexo-code/main/schemas/config.json",
  "model": "google/gemini-2.5-pro",
  "theme": "grove",
  "provider": {
    "custom": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.minimax.cn/v1",
        "apiKey": "{env:CUSTOM_API_KEY}"
      },
      "models": {
        "MiniMax-M2.7": { "name": "MiniMax M2.7" }
      }
    }
  }
}
