# Native Memory operation UI localization

The new App operation view supplies complete English, Simplified Chinese (`zh`) and Traditional Chinese (`zht`) phrases. Other App locales retain the established English fallback. Terminal operation controls retain the existing English-only terminal localization boundary; this slice does not claim translated terminal controls.

The review uses maintained [VS Code Simplified Chinese](https://raw.githubusercontent.com/microsoft/vscode-loc/main/i18n/vscode-language-pack-zh-hans/translations/main.i18n.json), [VS Code Traditional Chinese](https://raw.githubusercontent.com/microsoft/vscode-loc/main/i18n/vscode-language-pack-zh-hant/translations/main.i18n.json), [Firefox Simplified Chinese permissions](https://raw.githubusercontent.com/mozilla-l10n/firefox-l10n/main/zh-CN/browser/browser/preferences/permissions.ftl), [Firefox Traditional Chinese permissions](https://raw.githubusercontent.com/mozilla-l10n/firefox-l10n/main/zh-TW/browser/browser/preferences/permissions.ftl), and the [Taiwan Ministry of Education concise dictionary](https://dict.concised.moe.edu.tw/page.jsp?ID=9&la=0&powerMode=0). Existing Memory terminology is preserved where appropriate: 记忆/記憶, 工作区/工作區, 权限策略/權限原則, 预览/預覽, 重试/重試, 取消, 清除 and 记录/記錄.

Dream remains the feature name, rather than being translated into a sleeping metaphor. Memory generation and operation IDs remain opaque technical values. The labels for files, topics and processed entries are complete count-bearing phrases with unchanged named placeholders; the UI does not assemble locale-specific grammar. “Final receipt recorded” deliberately avoids implying that a completed domain receipt proves every filesystem cleanup has finished. “Committed” explains that explicit retry may still be needed for settlement.

“Shadow validation” is an existing technical mode, translated as 影子验证/影子驗證 with the explanatory clause that no topic was published. Region-specific wording for durable records and discarded prepared plans merits native-speaker review. This document records corpus-based review, not a claim of native-speaker certification. No old English key or value is changed. The new outcome group fixes the observed Traditional Chinese fallback recorded in BUG-20261015-293.

The focused dictionary test verifies every new key exists in both Chinese dictionaries, differs from English, and preserves placeholder names. Actual production browser and native-window runs passed all 16 checks with five provider requests per run, including en/zh/zht preview screenshots and complete localized outcomes. These counts include setup and explicitly requested capture/Dream work; passive locale review made no provider request.
