# BUG-20261015-126: Active Stop left a native Plan approval visible

- **Scope:** New native Plan durable approval draft; actual native server and App renderer.
- **Observed:** Active interruption cancelled the durable pending review and GET returned an empty Question list, but the live approval dock stayed visible without a reload. The unchanged production renderer's wait failed after25 seconds. Captured native SSE contained Asked and no Rejected; the screenshot still showed approval controls after Stop.
- **Expected:** Accepted active Stop removes the live review through the ordinary canonical Question rejection event. It must not claim to reject an already-approved decision or an old/deleted Session incarnation.
- **Cause:** The Plan wait's interruption finalizer changed its receipt to cancelled but omitted Question.Event.Rejected. App Question stores remove pending requests on Replied/Rejected events; a successful list assertion did not verify that live update path.
- **Fix:** Under the original lifecycle claim and a short mutation lease, lock the receipt, verify it is still pending, write cancelled, and publish Rejected once. A closing/retired claim cannot acquire the lease. A decision already settled by approval/rejection emits no extra rejection. Idle interruption remains unchanged and does not dismiss restored approvals.
- **Verification:** `bun run script/grok-native-plan-ui.mjs browser --stop-probe` passed against the unchanged production App artifact and repaired native backend: the dock disappeared without reload, the real SSE contained the matching Rejected event, and provider calls stayed at3. `bun test test/e2e/v2-plan.e2e.test.ts --test-name-pattern 'approval (interrupt|delete|unknown)'` passed3 tests/33 assertions, including one active-Stop event and no event targeting a deleted/recreated Session or a nonapproval decision. Package types are a separate final gate.
- **Occurrences:** One verified Plan integration failure. The analogous generic Question interruption path has not been reproduced or repaired in this record.

Shared integration verification: the combined native Plan and background Task approval suite passed 14 tests / 153 assertions; all 21 repository typecheck tasks passed. CLI and rebuilt Desktop recovery each passed 13 checks / 10 local-provider calls; the actual crash checkpoints passed 10 checks / six calls. This does not replace the separate pending UI acceptance.
