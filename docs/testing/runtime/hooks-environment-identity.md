# BUG-20261014-105: Host hook environment expansion and runner identity were incomplete

- **Scope:** Host hook discovery and shared command/HTTP dispatch.
- **Observed:** Static comparison found that configured command/URL references were not expanded at load time, runtime identity variables were absent, and unset plain command references could silently become empty shell strings.
- **Expected:** Expand plain references using per-hook environment before process environment; preserve unknown references and shell modifier forms; supply authentic event, hook, Session, and workspace identity at execution; reject unresolved plain command references before spawn.
- **Reference:** Pinned `xai-grok-hooks/src/env_expand.rs`, `config.rs` runner-reserved keys and handler parsing, and `runner/command.rs` execution environment and unresolved-reference preflight. The HTTP runner performs an additional URL expansion immediately before dispatch.
- **Reproduction:** Configure a command containing a single-quoted `${HOOK_SCRIPT}` with its path supplied by hook `env`, forge `GROK_SESSION_ID`, and read the actual environment in the script. Separately place a side effect before a reference to an unset plain variable.
- **Root cause:** The initial implementation passed configured environment to the shell but omitted the reference's separate load-time expansion and authentic runtime identity boundaries.
- **Fix:** Add shared expansion preserving modifiers/special parameters, strip reserved configuration keys, inject actual identity at dispatch, resolve URL variables at dispatch, and fail unresolved plain command references before spawning. Installed bundle behavior remains separate.
- **Verification:** Focused environment/host/Stop/observer suite passed 18 tests / 52 assertions. Apexo package typecheck passed. CLI passed four scenarios. The isolated installed comparator passed all 15 scenarios. The refreshed production Desktop artifact passed all four environment scenarios. The installed 1.0.52 runtime executed a command containing an unset plain reference; this differs from the pinned source preflight, which Apexo follows. The comparison records this difference explicitly rather than claiming equivalence. Command-local assignment and `read` variables are exempt from preflight, matching the pinned source.
- **Occurrences:** One static contract finding; no historical runtime occurrence count is inferred.
