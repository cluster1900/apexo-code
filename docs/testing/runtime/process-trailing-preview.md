# BUG-20261015-156: A quiet process retained a stale preview

- Status: integrated; the shared 21-file regression passed 141 tests / 803 assertions. All 21 workspace typechecks and shared CLI/rebuilt Desktop Monitor acceptance passed ten checks / 57 calls each; all twenty command-owned PIDs were absent after cleanup.
- Scope: native owned Shell and Monitor process output. One diagnosis episode, with repeated confirmation rather than independent historical occurrences.
- Observed: a sandboxed Monitor emitted stderr and stdout close together. Its live model notification contained both streams, but passive process output retained only the first snapshot while the process waited silently. A separate ordinary Shell regression (`FIRST`, a 30 ms delay, `LAST`, then a held gate) failed with `trailing chunk not persisted`.
- Expected: the final buffered chunk becomes visible within the bounded preview interval even if no later chunk arrives; the same process remains running.
- Cause: the shared output callback throttled writes to 200 ms but scheduled no trailing write. The next write depended on another chunk.
- Fix: one process-scoped worker consumes a coalesced dirty signal, waits 200 ms and persists only changed capture revisions. Monitor batching shares this worker and still wakes after retained capture reaches one MiB. Dirty signal replacement precedes the wait, so a chunk during the wait or database snapshot remains signalled. The worker is interrupted and joined before terminal writes on both success and failure; terminal storage also rejects late snapshot changes. There is no per-line detached fiber or quiet storage polling.
- Verification: the ordinary Shell regression changed from one failure to a pass. The isolated seven-file owner/provider/store/Plan union passed 28 tests and 332 assertions, including real process cancellation/deletion, same-PID held output, Monitor overload kill-and-join and post-capture-limit notifications. Existing foreground sandbox Bash passed one test and 25 assertions. Core and Apexo package typechecks passed. CLI/Desktop acceptance is recorded separately in the feature document.
