## Non-defect observations and coverage limits

- One early Desktop attempt wrote correct files and passed its test, but the final provider turn remained unfinished for 51 seconds and was manually stopped. A fresh coding repeat completed in 27 seconds. This is retained as an unresolved latency observation, not a verified fix or a proven deterministic defect.
- A direct automation fill containing multiple newlines collapsed its first line break. A real Shift+Enter sequence preserves every newline in the persisted prompt. Native multiline paste was not independently characterized; no product conclusion is drawn from the fill method.
- Initial detached-server lifetime, wrong TUI launcher working directory, inherited script stdin, and native dialog paste timing were harness problems. Closed stdin was used for the decisive fork reproduction; the corrected terminal fixture starts from packages/apexo.
- Onboarding mode uses an in-memory database. Close/reopen tabs, native export, CLI disk-backed continuation and cross-client identity are tested; Desktop process-restart persistence is not. Application instructions prohibit restarting app/server processes.
- Memory management UI is capability-gated to the grok-build profile on V1; the tested default Apexo profile intentionally hides it. CLI memory status is verified. No claim is made for an unavailable profile-specific panel.
- macOS only. Windows/Linux installers, signing/notarization, first-time OAuth, live third-party MCP/plugin account integrations, network outage injection, uninstall/migration and destructive data deletion are not exercised. Existing account configuration is preserved.
- Prior uncommitted audit drafts used a different SHA; their historical PASS claims are not counted. Historical #118/#121 targeted reproductions pass at this baseline.
