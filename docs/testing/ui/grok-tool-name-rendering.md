# BUG-20261018-402: Grok Build tool calls rendered differently in the CLI TUI and Desktop

- Scope: Fullscreen CLI TUI tool rows, Desktop timeline tool views and Desktop tool error cards, for the Grok Build tool names exposed to xAI models (`search_replace`, `run_terminal_cmd`, `read_file`, ...).
- Observed: In the fullscreen TUI a `search_replace` call rendered as a generic `⚙ search_replace [file_path=..., old_string=..., ...]` row with no diff and no error state; the same call on Desktop rendered as an Edit view but without the file name (the view reads `filePath`, the call carries `file_path`). A failed `search_replace` showed the raw title `search_replace` on Desktop, and the error card split the message at its first `": "`, so `Nearest match: line 4: ...` lost its label and the subtitle showed a truncated sentence.
- Expected: Both clients render a Grok-named call with the Apexo view of the equivalent tool (Edit diff, file name, red failed row) and show the full error text.
- Root cause: The TUI `toolDisplay` only recognised Apexo names, and neither client mapped Grok input field names. The minimal CLI already had its own mapping. The error card treated every `"x: y"` message as `"Kind: details"`.
- Fix: New shared `@apexo/core/util/grok-tool-display` (`canonicalToolName`, `canonicalToolInput`) used by the TUI tool switch and the Desktop tool part. Desktop error-card titles cover `edit`, `write` and the Grok names. The card only uses the `Kind: details` split when the head is a short label, not a sentence.
- Reproduction: In `packages/apexo`, `bun script/grok-slash-tui.mjs --edit-fuzzy` and `CHROMIUM_PATH=/usr/bin/google-chrome bun script/grok-slash-ui.mjs desktop --edit-fuzzy` (Desktop needs `packages/app` and `packages/desktop` builds).
- Verification: Both `--edit-fuzzy` flows pass 2/2 (diff rendered; miss shows `Nearest match: line 4: ...` and the file is unchanged). Regression flows pass: `grok-tasks-tui.mjs` (mini and `--fullscreen`), `grok-terminal-compat-regression.mjs --fullscreen`, `grok-slash-tui.mjs`, `grok-slash-ui.mjs desktop` 9/9. `bun test test/util/grok-tool-display.test.ts` 4/4.
