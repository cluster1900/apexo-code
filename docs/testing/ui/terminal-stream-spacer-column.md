# BUG-20261015-185: A new terminal stream inherited the preceding entry's column

- **Status:** Root cause reproduced and corrected; renderer suite, package types and actual packaged Plan acceptance passed.
- **Scope:** Mini CLI retained assistant/reasoning scrollback, native or compatibility transport. One observed product episode and its deterministic regression reproduction; repeated assertions are not independent occurrences.
- **Observed:** Packaged mixed-server Plan acceptance successfully posted approval, completed the provider turn and stored the exact `PLAN_UI_CONTINUED` text. The terminal instead painted `PLAN_UI` and `_CONTINUED` on separate lines at width 120. The unchanged exact-text assertion timed out. Preserved ANSI confirms the split was emitted by the renderer, not introduced by the headless terminal's capture.
- **Expected:** A new visible entry with an intervening spacer measures its first line from column zero. Short replies must not wrap at the previous entry's trailing column. Chunks within the same streaming entry retain their existing continuation behavior.
- **Reproduction:** Run `bun script/grok-native-terminal-tui.mjs --mixed --desktop --plan` from `packages/apexo`. The deterministic `scrollback.surface.test.ts` cases render a 36-character user entry at width 40, then a short assistant or reasoning entry. Both failed before the fix: the first line had room for only two characters.
- **Root cause:** `RunScrollbackStream.createEntry` created its retained surface before writing the pending inter-entry spacer. OpenTUI captures `firstLineOffset` at surface construction when `startOnNewLine` is false. The spacer later moved output to a new line, but the already measured content still wrapped using the previous tail column.
- **Fix:** Compute the pending spacer before surface creation and select `startOnNewLine` whenever that spacer requires a new line. Preserve deferred spacer emission for empty entries and existing continuation semantics for the same group. No transport, stored content or test timeout changes.
- **Verification:** Both new regression cases failed before the correction. The complete scrollback file then passed nineteen tests / 75 assertions, and `bun typecheck` passed in `packages/apexo`. Source CLI and packaged mixed-server Plan mini/fullscreen each passed four checks / five provider calls, preserving the original exact-text assertion; packaged permission, active Stop and reconnect also passed in both modes. This is Apexo's renderer; no Grok runtime is embedded or modified.
