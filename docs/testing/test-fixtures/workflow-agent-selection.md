# BUG-20261015-345: Workflow agent-selection fixture contracts

- **Scope:** New Workflow selection acceptance fixtures; no production behavior changed by these corrections.
- **Observed:** The initial intentional revocation fork escaped the test scope as a failure. A later HTTP probe sent a bodyless resume request and received 400. The next probe expected the read tool to expose the word `denied`; it instead rendered the native generic `Unable to read` error. Assertions inside provider callbacks caused retries that exhausted the queued responses and returned the fixture's default `ok` response, obscuring the failed assertion.
- **Expected:** The fixture observes deliberate failure as an Exit, supplies the declared resume payload, and verifies actual tool output outside the provider response callback.
- **Reproduction:** Run the new Workflow admission/provider tests with the intentional-failure fork lacking `Effect.exit`, omit the `Workflow.Resume` JSON object, or assert `/denied|reject/` inside the provider callback for a denied native read.
- **Root causes:** Three distinct fixture contract mistakes, not recurring production failures: unobserved expected child failure; omitted required HTTP payload; assertion against noncontractual error wording inside a retryable transport callback. These are not counted as repeated occurrences of one root cause.
- **Fix:** Fork `Effect.exit` and join the outcome. Send `{}` to resume, whose endpoint declares `Workflow.Resume`. Capture provider bodies, assert their actual system/model/tool-result fields after completion, expect the native generic read error, and prove a public-file positive control alongside the private-file nondisclosure check.
- **Verification:** Pinned Bun 1.3.14, `bun test test/workflow test/e2e/v2-workflow-agent.e2e.test.ts test/e2e/v2-workflow-model.e2e.test.ts --timeout 30000` from `packages/apexo`: 39 tests passed, zero failed, 268 assertions. The earlier runs retain the respective first-failure evidence; the corrected result is not claimed as a production fix. A sandboxed run failed to bind a local listener before HTTP assertions and used default Bun 1.4.2; it is excluded from acceptance evidence.
