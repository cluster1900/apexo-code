# BUG-20261015-034: Compaction regression timing failures during a shared build

- **Scope:** Existing compatibility `test/session/compaction.test.ts` cases in the live compaction-hook verification gate.
- **Observed:** The first integrated three-file run passed 55 tests, skipped one, and failed six in 57.96 seconds. Five cases reached the existing five-second test timeout: full-summary fallback for an oversized recent turn, retained media fallback, split-turn retention, repeated-summary anchoring, and plugin context serialization. The retry-backoff cancellation case settled with the expected interrupt but measured 327 ms against its existing less-than-250-ms assertion. The new native hook tests and existing observer tests passed in that run.
- **Expected:** The same focused regression command completes within its existing assertions and time budgets.
- **Reproduction:** From `packages/apexo`, run `bun test test/session/native-compaction-hooks.test.ts test/plugin/hook-observer.test.ts test/session/compaction.test.ts`. The failing run overlapped a coordinated Desktop build and package typechecks. A contemporaneous process snapshot showed Electron Vite at approximately 175% CPU and four system metadata workers at approximately 47–53% CPU each.
- **Root cause:** Unresolved. Host contention is consistent with the timing pattern, but the observations do not prove a production defect or establish contention as the sole cause. No functional assertion failure was observed outside these timing limits.
- **Action:** Preserve the failing results and rerun the identical command after the owned build and typecheck jobs settled. No source, test assertion, retry policy, or timeout was changed.
- **Verification:** The unchanged isolated rerun passed 61 tests, one existing skip, and 199 assertions in 20.39 seconds. The later complete unit gate also passed 4,017 tests with zero failures, including this file, using its existing repository-wide 30-second test timeout. These passing runs do not isolate the original cause or establish a code fix for the focused timing failure.
- **Status:** Timing sensitivity remains an evidence-limited investigation. Revisit if it recurs under an isolated workload; do not increase timeouts based on this run alone.
- **Occurrences:** One integrated verification episode. Its six timing failures and subsequent unchanged rerun are not six independent occurrences.
