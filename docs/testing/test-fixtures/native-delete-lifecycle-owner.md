# BUG-20261015-026: Native deletion fixture bypassed lifecycle ownership

- **Scope:** `packages/apexo/test/session/native-delete.test.ts`, following integration of shared Session lifecycle retirement.
- **Observed:** The complete package gate failed the expected `closing` boundary with `removed`. An isolated unchanged run reproduced the failure in approximately 62 ms, before any timeout: removal finished while the fixture's control remained active.
- **Expected:** The fixture exercises the real native execution owner. Deletion begins its cancellation finalizer, waits while that finalizer is held, and preserves the Session row and captured hook snapshot until cleanup settles.
- **Root cause:** The fixture replaced `SessionExecution.Service` with a hand-built raw `SessionRunCoordinator`. It exposed control and interrupt methods but omitted the lifecycle claim and owner registration implemented by `SessionExecutionLocal`. Shared removal retires registered owners; the fixture's unregistered work was therefore invisible. The earlier deletion implementation called the replacement's interrupt method directly, which had concealed this incomplete replacement contract.
- **Fix:** Remove the hand-built execution layer and explicitly replace the execution node with the actual `SessionExecutionLocal.node`. Keep the held-finalizer behavior and all assertions unchanged. No production code, timeouts, or lifecycle semantics change.
- **Reproduction:** From `packages/apexo`, run `bun test test/session/native-delete.test.ts` against the old fixture. The isolated result is zero passing tests and one failure with `Expected: "closing"`, `Received: "removed"`.
- **Verification:** The repaired off-tree fixture passed one test and eight assertions in approximately 67 ms. It verifies row and snapshot visibility during cancellation, joined finalizer settlement, and removal afterward. The focused gate (`bun test test/session/native-delete.test.ts test/session/lifecycle.test.ts test/session/native-removal-lifecycle.test.ts test/session/child-reuse-removal.test.ts test/session/nested-retirement.test.ts`) then passed 20 tests and 69 assertions across five files.
- **Status:** Fixture-only repair integrated; the same focused five-file suite passed live with 20 tests / 69 assertions. The complete aggregate rerun passed 4,017 tests with zero failures and all six Turbo tasks exited successfully.
- **Occurrences:** One integration failure. Full-suite and isolated reproductions are evidence for the same occurrence.

This differs from [the earlier production deletion bug](../runtime/native-session-delete-ownership.md): production now owns cancellation through SessionLifecycle; this fixture had not migrated to that ownership contract. It also differs from [the owner settlement defect](../runtime/session-owner-settlement.md), where a registered worker's cancellation waiter did not settle.
